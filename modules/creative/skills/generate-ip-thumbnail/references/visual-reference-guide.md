# Visual Reference Guide

## Purpose

Use the bundled thumbnails to study how a content Shell becomes a visible subject-plus-relation. Learn transferable decisions, not surface styling.

## Evaluation Lens

For each reference, ask internally:

1. What abstract Core might the content communicate?
2. What concrete Shell gives the audience an immediate entrance?
3. Which objects are actually visible?
4. What human-object, object-object, action, conflict, or spatial relation makes the Shell legible?
5. Would the image still communicate “what is happening” without its added typography?

Prefer references whose scene and relationship survive that final test.

## Learn These Principles

- **Shell-first expression:** show the experiment, use case, event, conflict, or human experience instead of illustrating an abstract concept.
- **Title-cover decoupling:** let the external title name or frame the Shell while the cover shows what is happening.
- **Object-plus-relation:** make a phone, protective device, underwater scene, computer, document, or interface meaningful through holding, comparing, testing, confronting, operating, observing, or immersion.
- **Strong single focus:** let one decisive relationship survive thumbnail scale.
- **Series coherence without a frozen template:** unify varied Shells through finish, contrast, framing discipline, lighting, and information density.

## Do Not Copy

Do not reproduce a creator's face, brand identity, logo treatment, typography, exact staging, or composition. Do not infer that text-heavy covers are desired because some references contain large words. The target skill defaults to no added text.

Treat screenshot grids, large typography, arrows, punctuation, isolated logos, and mechanical left-right arrangements as observations or counterexamples. A successful target image must carry its Shell through concrete objects and relations without relying on explanatory words.
