# Creative

负责创作方向、风格选择、视觉叙事、镜头方案与风格专属组件。风格根据内容理解目标和可用材料选择。

**输入**：Editorial 制作稿、内容依据、受众和交付约束。

**输出**：供用户确认的创作方向、CreativePlan、素材需求和技术实现请求。

保留 Vox、白板、图表等风格各自的视觉语法；共享运行时不意味着画面必须相似。正式内容不复用示例中的事实或未授权素材。

## Huashu 本土化原则

- 保留原有 Canvas 场景、解说语法和各风格组件，作为 Creative 可调用的表达能力。
- 先读制作稿的理解目标与材料，再选风格；缺少真实档案材料时不伪造 Vox 式截图或证据。
- 演示人物、示例数字和示范叙事只用于参考，正式使用须有本项目内容来源与素材许可。
- 一帧先行用于尽早检查视觉方向，不把原项目叙事节奏变成所有作品的统一模板。
- 共享 Canvas 与字体是 Production 支撑；镜头构图和视觉语言由具体 Creative 风格决定。
