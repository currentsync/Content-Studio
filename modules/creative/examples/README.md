# 本地创作示例

这里的代码和画面用于学习表达方式、预览能力和改编工程；示例本身不构成正式内容。正式项目的观点来自 Editorial，风格由 Creative 按理解目标和真实材料选择。

## 可预览的示范

| 示例 | 适用表达 | 使用前提与限制 |
| --- | --- | --- |
| `t1_3b1b` | 把机制、流程或数学关系画成图解 | 使用项目自己的定义、公式与单位；演示内容仅供参考 |
| `t2_keynote_ui` | 产品步骤、界面交互和状态变化 | 正式成片使用真实或清楚标记为重绘的界面 |
| `t3_finance_chart` | 数据比较、变化与转折 | 演示数字为虚构；正式数据要有来源、单位和可复核口径 |
| `y1_kurzgesagt` | 抽象概念、系统和尺度变化 | 需要有依据的概念模型；示范角色素材不随本仓库提供，需使用自有或明确授权的素材 |
| `y2_vox` | 用档案、照片、地图或文档推进调查式解释 | 必须有可合法使用的真实材料；没有材料时不要制作假档案；示范角色素材需自行提供 |
| `y3_whiteboard` | 步骤推导、论证结构和概念关系 | 画面需要跟随实际讲解顺序，不用板书装饰替代推理；示范角色素材需自行提供 |
| `y4_storytime` | 创作者亲历故事、反应与停顿 | 需要自备有权使用的角色素材与本人经历，不能把虚构经历讲成真人故事；Huashu 角色帧不包含在本仓库 |
| `y5_kinetic_type` | 短句、概念强调和节奏化文字 | 需要精简文案；文字动效不能制造原文没有的强调结论 |
| `long_scroll` | 多个连续世界、长距离移动和风格过渡 | 代码保留三段演示场景；角色帧需使用自有或明确授权的帧库；完整长片需另行补齐场景与素材 |

## 参数化动画语法

八个可运行语法由本模块 Creative 选择；图解艺术场景另在 `../canvas/scenes/` 注册。它们是能力菜单，不是必须采用的统一画风。

```powershell
uv run python modules/production/scripts/render_canvas.py --film demos/y2_vox --preview --out preview.mp4
```

预览中的论文数字、剪报、角色和布局属于演示素材。Huashu 角色图和帧仅限上游 Skill 的示范用途，不随 MIT 授权给 ContentStudio 作其他用途，因此不纳入本仓库。`y1_kurzgesagt`、`y2_vox`、`y3_whiteboard`、`y4_storytime` 和 `long_scroll` 的相关角色镜头需要自备或明确授权的素材才能完整运行。开始正式项目时，将适用的机制改编到项目自己的 `creative/native/`，换成自有或明确授权的稿件和资产后再请求用户确认视觉方向。
