# ChannelShell to Title and Opening

Read `../../theory/shell-theory.md` and `../../theory/channel-adaptation-theory.md` completely.

Require the current Core and selected ChannelShell files from the project snapshot plus channel and format. Block if the channel Shell is missing, abstract, or belongs to another target.

1. Treat the selected ChannelShell's object, task/problem, tension, promise, and Core bridge as invariants.
2. Generate 4–6 distinct pairs without changing the underlying entrance.
3. Compress the ChannelShell into the title; make the opening immediately pay off that promise.
4. For `format=video`, write a speakable scene/task → tension → question → Core handoff.
5. For `channel=xiaohongshu, format=graphic`, write a concise note lead or first-body-page handoff that establishes scope and expected takeaway; do not imitate a spoken video hook.
6. Return candidates in the conversation. After the user chooses, save the selected title/opening to the channel's `packaging.md`; return the artifact path and references to Workflow for status registration. Do not edit the snapshot..

Reject greetings, unrelated curiosity bait, hidden Shell changes, full scripts, CTAs, and cover instructions.
