# Core Formation Guidance

## Purpose

Transform a raw idea into a Core without confusing intuition, learning, and authorship.

## State model

```text
idea -> clarification -> confirmed meaning -> knowledge map
     -> minimum-sufficient learning -> confirmed understanding -> Core
```

A transition requires evidence that the preceding state is complete. User impatience alone is not evidence.

## Boundary definitions

- **Idea:** An observation, question, feeling, analogy, hunch, or partial claim. It may be ambiguous or wrong.
- **Clarified meaning:** The interpretation the user has selected or restated as their intended subject. It is not yet a validated claim.
- **Knowledge map:** The real concepts and evidence landscape relevant to that meaning, including disagreements and category boundaries.
- **Minimum-sufficient learning:** The smallest body of knowledge needed to state the Core responsibly and understand its limitations.
- **Core:** A scoped, supportable content proposition the user understands and endorses. It is not a hook, format, or script.

## Authorship boundary

The agent may propose interpretations, surface implications, test coherence, and explain evidence. The user owns the viewpoint and value judgment. When multiple defensible interpretations remain, preserve the choice instead of collapsing them into the most marketable one.

## Evidence discipline

Separate four epistemic statuses:

1. **Well-supported knowledge:** Findings or definitions with strong, relevant support.
2. **Theory or model:** An explanatory framework that may organize evidence without being settled fact.
3. **Contested or limited claim:** Evidence is mixed, indirect, context-dependent, preliminary, or disputed.
4. **User interpretation:** A personal inference, normative preference, or creative thesis.

Use calibrated language. Correlation is not causation; a mechanism that sounds plausible is not evidence; a named concept is not automatically the correct explanation.

## Minimum-sufficiency test

The user is ready to define a Core when they can, at an appropriate level:

- state the central distinction in their own terms;
- identify what supports the claim;
- name at least one important limit or counterpoint;
- avoid the main misleading overstatement;
- choose the intended scope and viewpoint themselves.

If one of these is missing and materially affects accuracy, return to learning or clarification.

## Handoff boundary

The final Core package may feed two separate downstream paths:

- content development: Core -> video or written content;
- packaging: Core -> Shell -> title, opening, and thumbnail.

Do not perform either path inside this skill.
