# Bilibili Shell

Read `../../theory/shell-theory.md` and `../../theory/channel-adaptation-theory.md` completely.

Require the current Core and selected BaseShell paths from the project snapshot plus `channel=bilibili`, `format=video`.

Generate 3–5 genuinely different Bilibili expansions of the selected BaseShell. Each may retain context, mechanism-level tension, exploration, and multiple dependent facets, but must have one central problem. For every candidate state the preserved BaseShell elements, emphasized facet, bridge to Core, narrative capacity, and risks.

Return concise candidates in the conversation. Do not choose a winner or create Title, Opening, Thumbnail, or body content. After the user chooses, save only the selected result to the channel's `shell.md`; return the artifact path and references to Workflow for status registration. Do not edit `project.yaml`..
