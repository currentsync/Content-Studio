# Editorial Theory

## 1. 定义与边界

内容组织分两级。BaseContent 把 confirmed Core 组织为平台无关的**知识依赖路径**；ChannelContent 再把它实例化为特定渠道与 format 的**消费路径**。先决定讲什么、依赖什么，再决定页面、段落、时间与视觉如何降低理解成本。

它重组呈现，不改写主张。它不是：

- Shell、Title、Opening 或 Thumbnail；
- 默认的逐字稿；
- 预算、人员、场地、排期、通告单等制片管理；
- 为维持注意力而添加的虚假悬念。

## 2. 理解路径

每个内容单元只承担清晰职责，例如：建立前置知识、定义概念、显现机制、提供证据、区分误区、演示应用或完成 Core。

按理解依赖排序，而不是按研究资料被发现的顺序。每个单元都应回答：

1. 观众在此之前知道什么？
2. 这一单元让其新增什么理解？
3. 用什么材料承担该变化？
4. 为什么下一单元现在可以成立？

不能推进理解的重复、装饰案例和包装语言应删除。

## 3. 证据与解释工具

概念、案例、比较、证据、演示、图表、实验和个人经验都有具体职责。案例可以说明或显现主张，但单个轶事不能独自支持普遍结论。视觉只有在降低理解负担时才使用。

`not_claiming` 与 `uncertainties` 应出现在观众最可能过度推广结论的位置，而不是埋在末尾免责声明中。

## 4. BaseContent

BaseContent 只包含知识单元、依赖顺序、证据/案例职责、范围、排除项与不确定性。不得提前写入 B站章节、小红书页面、视频镜头、Opening、节奏技巧或 CTA。

## 5. 媒介原生组织

### Bilibili 视频

允许较完整的因果链、多个证据层与耐心澄清。节奏来自理解持续推进，不来自强行悬念。主体从上游 Opening 的交接点开始。

### 小红书视频

保留一条主导理解路径，优先可立即识别的案例、演示、对比和视觉。删掉分支，不要用加速念完代替取舍。

### 小红书图文

每页一个主导信息单元，滑动顺序形成累积理解。首张主体页不是封面。图示、对照、表格与标注服务于可扫读和可回看。

### 文章

标题层级暴露论证结构，段落承载需要连续性的推理，图表、案例与侧栏承载适合分离的信息。为重读与引用优化，不机械模仿口语节奏。

不同媒介之间不得机械切片或转录。每个媒介必须从同一 BaseContent 重新组织理解路径；不得从另一个 ChannelContent 转制。

## 6. 与包装分支的接口

主体内容接收上游 Opening 带来的受众，并用简洁过渡进入 Core。可以描述 `transition_from_opening`，但不在 Editorial Plan 内重写 Opening。

结尾应解决、应用或收束 Core，不默认加入 CTA 或分发包装。最终 Assembly 只校验 Editorial Plan 与包装产物指向同一 Core、媒介约束兼容；不会把两条分支混写成新的语义产物。

## 7. 质量门禁

- 每个单元推进对 unchanged Core 的理解。
- 所有主张位于 `knowledge_basis` 与 `scope` 内。
- 示例准确说明，证据按强度支撑。
- 结构是媒介原生的。
- 方案足以进入脚本或拍摄准备，但不越权承担制片。
- 无包装产物、二次钩子或不必要 CTA。
