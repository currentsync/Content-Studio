# Channel Adaptation Theory

## 1. 两级内容与两级壳

Core 后有两条并行链，每条链都先建立平台无关语义，再做渠道实例化：

```text
Core ─┬─→ BaseContent ─→ ChannelContent
      └─→ BaseShell   ─→ ChannelShell
```

- **BaseContent**：讲什么、知识依赖、证据与案例各承担什么职责、关键解释顺序和边界。它不是脚本、视频段落或图文卡片。
- **ChannelContent**：在不改变 BaseContent 与 Core 的前提下，按平台和 format 重新组织消费单元。
- **BaseShell**：平台无关的真实传播母壳，说明受众通过什么具体问题、场景、任务、异常或对象进入 Core。
- **ChannelShell**：从 BaseShell 选择并放大最适合该渠道的一个切面。它不是改写 Core，也不是另造热点。

ChannelContent 与 ChannelShell 是两个独立转换；前者组织主体知识，后者确定传播入口。二者只通过同一 Core、渠道与 format 做兼容校验，不能互相替代。

## 2. 渠道实例化不变量

1. 保留 Core 的主张、范围、`not_claiming` 与不确定性。
2. 保留 BaseContent 的知识依赖，允许删减不适合单篇承载的分支，但必须声明覆盖范围。
3. ChannelShell 必须能追溯到一个已选择的 BaseShell；不引入无关热点、虚假冲突或无法兑现的结果。
4. 渠道转换是重新编排，不是裁剪、转录、拆页或改写成平台语气。
5. 每个渠道产物只绑定一个 `channel + format`；跨渠道应产生独立 revision。

## 3. Bilibili

### Shell

B站允许把 BaseShell 展开为较完整的问题：保留背景、机制性张力和探索过程，让入口能支撑较长叙事。具体不等于狭窄；它可以承载多个相互依赖的切面，但中心问题必须唯一。

### Content

B站视频允许较完整的因果链、多个证据层、反例与耐心澄清。段落按理解推进组织，主体从 Opening 的交接点进入，不重复制造第二个钩子。

## 4. 小红书

### Channel Shell

小红书 Shell 的核心不是短标题或大字封面，而是从 BaseShell 中选择一个能被快速判断、值得保存的单一切面：

- 明确对象：Agent 评测、浏览器收藏、后台流程、某个模型或具体工具；
- 明确任务或困境：怎么搭、怎么判断、怎么定位、怎么让产品被推荐；
- 明确内容承诺：知识地图、清单、工作流、评测框架、公开构建记录、结果与复盘；
- 使用当前场景语言，让目标用户一眼判断“是否与我现在要做的事有关”；
- 结果可以具体，但不得把偶然结果包装为普遍保证。

典型入口包括：

- **任务地图**：`Agent 评测怎么搭？一份轻量全览`；
- **机制切片**：`为什么 Transformer 上下文不等于真正的 Memory`；
- **公开构建**：`我们把后台做成全自动化，流程是怎么运作的`；
- **可验证结果**：`模组下载量突破 50 万：哪些动作真正起作用`；
- **工具工作流**：`用一个模型把 7 小时课程整理成可回看的知识结构`。

拒绝：只有“重磅”“必看”的空泛刺激；把宏大行业命题原样搬来；为了平台感加入与 Core 无关的热点；把封面字号、配色或排版当作 Shell。

### Channel Content — graphic

图文不是视频稿拆页。将内容重组为可扫读、可回看、可单页定位的知识单元：

1. 封面之后先给范围、对象与读完所得，建立保存理由。
2. 每页只承担一个认知动作，如定义、地图、步骤、对比、诊断、示例、结果、限制。
3. 页面之间形成任务顺序或理解依赖；不能只是一组并列金句。
4. 优先使用结构图、流程、清单、对照、标注截图和证据卡；视觉承担解释，不做装饰。
5. 在容易误用的位置放条件与边界；最后提供可执行收束或索引，而非强行 CTA。

### Channel Content — video

小红书视频保留一条主导路径：迅速显现对象与任务，通过一个演示、案例、对比或过程推进到结论。删掉旁支，不通过加速念稿压缩 B站结构；镜头单元应对应真实的认知变化。

## 5. 下游接口

Title、Opening 与 Thumbnail 只能消费已确认的 ChannelShell。`format=graphic` 时 Opening 指笔记首段/首张主体页的进入方式；`format=video` 时 Opening 指可说、可演示的视频开场。Thumbnail 独立消费 ChannelShell 的对象与关系，封面方法论不写入 Shell Skill。
